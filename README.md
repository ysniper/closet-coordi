# 옷장 코디 (closet-coordi)

내 옷을 사진으로 등록해 두면, 오늘 날씨와 상황을 보고 "오늘 뭐 입지?"에 답해 주는 앱.
아이폰과 안드로이드 모두 지원 (Expo / React Native).

기획서: 프로젝트 파일의 `옷장코디앱_기획서.md` 참고.

## 지금 되는 것 (1단계 뼈대)

| 탭 | 기능 |
|---|---|
| 오늘 | 현재 위치 날씨 표시(Open-Meteo, 무료), 오늘 상황 선택, 내 옷장 옷으로 코디 2~3개 규칙 기반 추천, 코디 저장 |
| 옷장 | 등록한 옷 격자 보기, 종류별 필터, 상세 보기/삭제, 옷장 분석(색상·종류·계절·브랜드 통계) |
| 등록 | 옷 사진 + 택 사진 촬영/앨범 선택, 종류·색상·브랜드·사이즈·소재·계절·두께·상황 입력 |
| 저장 | 저장한 코디 모아보기 |
| 내 정보 | 키·몸무게·성별, 선호 스타일 사진 등록, 선호 스타일 버튼 선택 |

데이터는 폰 안에만 저장됩니다 (서버·로그인 없음).

## 다음 단계
- 옷 사진 → AI(Claude)가 종류·색상·소재·계절 자동 분류, 택 사진에서 브랜드·사이즈 읽기
- 선호 스타일 사진 → AI가 취향 요약
- 옷장 분석에 AI 취향 해석 추가
- 코디 추천을 AI로 교체 (날씨 + 상황 + 선호 스타일 + 옷장 분석)

## 내 폰에서 실행해 보기 (개발자 아니어도 가능)

1. 컴퓨터에 [Node.js](https://nodejs.org) (LTS) 설치
2. 이 저장소를 내려받고 폴더에서 터미널 열기
3. 아래 명령 실행
   ```bash
   npm install
   npx expo start
   ```
4. 폰에 **Expo Go** 앱 설치 (App Store / Play 스토어, 무료)
5. 터미널에 뜬 QR 코드를 폰 카메라(아이폰) 또는 Expo Go 앱(안드로이드)으로 스캔

컴퓨터와 폰이 같은 Wi-Fi에 있어야 합니다.

## 개발 명령
```bash
npx tsc --noEmit   # 타입 검사
npx expo lint      # 린트
```

## 폴더 구조
```
src/app/          화면 (탭 하나 = 파일 하나)
src/components/   화면에서 같이 쓰는 부품 (버튼, 카드, 칩 등)
src/lib/          데이터 저장, 날씨, 추천 로직, 사진 선택
```
