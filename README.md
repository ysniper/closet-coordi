# 옷장 코디 (closet-coordi)

내 옷을 사진으로 등록해 두면, 오늘 날씨와 상황을 보고 "오늘 뭐 입지?"에 답해 주는 앱.
아이폰과 안드로이드 모두 지원 (Expo / React Native).

기획서: 프로젝트 파일의 `옷장코디앱_기획서.md` 참고.

## 지금 되는 것

| 탭 | 기능 |
|---|---|
| 오늘 | 현재 위치 날씨(Open-Meteo, 무료), 오늘 상황 선택, 내 옷장 옷으로 코디 추천(AI 연결 시 AI, 아니면 규칙), 코디 저장 |
| 옷장 | 등록한 옷 격자 보기, 종류별 필터, 상세 보기/삭제, 옷장 분석(AI 취향 해석, 다음에 사면 좋을 옷 추천, 색상·종류·계절·브랜드 통계) |
| 등록 | 옷 사진 + 택(케어 라벨) 사진 → AI가 종류·색·소재·브랜드·사이즈 자동 입력, 모델명이 보이면 인터넷 검색으로 제품명·정가까지 |
| 쇼핑 | 매장에서 가격표 택 촬영 → 사이즈 판단, 겹치는 옷, 사면 가능한 코디, 살지 말지 결론 → 샀으면 바로 옷장 등록 |
| 저장 | 저장한 코디 모아보기 |
| 내 정보 | 키·몸무게·성별, 선호 스타일 사진 → AI 취향 요약, 선호 스타일 버튼, AI 연결(본인 Gemini/Claude 키) |

데이터와 AI 키는 폰 안에만 저장됩니다 (서버·로그인 없음). AI는 본인 키로 직접 호출하며 Gemini는 개인 무료 사용량이 있습니다.

## 다음 단계

- 화면 디자인 다듬기
- 공개 배포용 서버(키 없이 쓰는 구조)

## 내 폰에서 실행해 보기 (개발자 아니어도 가능)

1. 컴퓨터에 [Node.js](https://nodejs.org) (LTS) 설치
2. 이 저장소를 내려받고 폴더에서 터미널 열기
3. 아래 명령 실행
   ```bash
   npm install
   npx expo start
   ```
4. 폰에 **Expo Go** 앱 설치 (App Store / Play 스토어, 무료)
5. 터미널에 뜬 QR 코드를 폰 카메라(아이폰) 또는 Expo Go 앱(안드로이드)으로 스캔

컴퓨터와 폰이 같은 Wi-Fi에 있어야 합니다.

## 개발 명령
```bash
npx tsc --noEmit   # 타입 검사
npx expo lint      # 린트
```

## 폴더 구조
```
src/app/          화면 (탭 하나 = 파일 하나)
src/components/   화면에서 같이 쓰는 부품 (버튼, 카드, 칩 등)
src/lib/          데이터 저장, 날씨, 추천 로직, 사진 선택
```
